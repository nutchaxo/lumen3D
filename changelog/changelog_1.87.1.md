## [FIXED]
- **The viewer no longer fires hundreds of requests per page**: opening `viewer.html` on a 3D dataset issued 247 requests in a burst, enough for a host that bans an address on a spike (bemine) to cut the operator off. The plugin trust check re-read every file of every plugin on every page load, each as a conditional request, and the Advanced Studio alone ships 49 files. A cold load now makes 114 plugin-file requests instead of 163 (191 requests in all instead of 247, measured in the browser), and a second load of the same page makes none (none reach the network, about 70 requests remain, all unrelated to plugins). Compare panels and the 2D page profit the same way.
- **Plugin requests stay below a burst**: at most six plugin files are requested at the same time across all plugins, so a cold cache no longer opens a hundred connections at once.

## [CHANGED]
- **Plugin files are cached for good**: each file of a plugin is requested as `<file>?v=<first 16 hex of the plugin's content hash>`, and the server answers any file under `js/modules/` carrying `?v=` with `public, max-age=604800, immutable` (`plugin.json` and `lang/*.json` included; Python server and root `.htaccess`). A plugin that changes gets new URLs, so nothing is ever revalidated. The verification is unchanged: the bytes run are the bytes hashed and must equal the server's vouch. When the bytes read from the browser cache do not match, they are read once more past the cache before the plugin is refused, so a stale cache entry cannot quarantine a good plugin and a really modified file is still refused. A static host without a server vouch stamps each file with the head of its release-manifest hash.
- **The Studio's plugins load on first use**: plugins of the `studio` placement (the Advanced Studio, 49 files) are no longer fetched, verified or run when `viewer.html`, `2d.html` or `compare.html` start. They load when the Studio opens (`PluginRegistry.loadLazy('studio')`, started by `StudioEditor.setModeLoader`), the Studio's view switch shows a translated *Loading…* entry meanwhile, and a failure leaves the Simple view fully usable with a translated message. A page that never opens the Studio makes no request under `js/modules/studio/`.
