## [FIXED]
- **The Studio no longer asks a pointless export question**: a PNG export of a figure already shown at native lossless quality asked to choose between *Native lossless* and *This picture*, which are the same image. That figure is now exported straight away; the question remains for a preview, where the two differ.
- **The Studio's frame-wait message tells the truth**: on a timelapse, a figure opened while its frame was still loading said *Loading frame N again for its native picture…* although the native pass only waits for that frame's own load to finish and loads nothing again. It now says *Waiting for frame N to finish loading for its native picture…* (new key `studio.nativeWaitFrame`, four locales); the old message stays for the case where the frame really is loaded again.
