# Captures of 2026-11 (platform 1.76.0): callouts manifest

Source of the viewer captures: `DATA_WEB/3d/F6TEST-E85` (format 6) and `DATA_WEB/3d/F5TEST-E85` (format 5), on the local dev server (`python dev_server.py --dev-trust-local`), software WebGL (SwiftShader). The viewer shows the dataset title stored in its metadata ("Egfl7eGFP-E85-Em1-… [format 5 test] [format 6 test]"), not the folder name.

The GPU memory figures and the colours of the quality guide come from the budget of this software renderer (256 MB). A real card gives other colours. The times of the guide come from the download speed measured on the capture machine (about 45 to 66 Mb/s); they change from one run to the next.

## Admin, four UI languages (`DOCS/admin-guide/img/`, `img-en/`, `img-es/`, `img-nl/`)

Captured on the local dev server, logged in with the local admin account (password from the environment only, nothing written to the repo). The admin tabs are read-only: the integrity check (`Relancer` / `Run again` / `Repetir` / `Opnieuw uitvoeren`) reads, it modifies nothing. The Data updates tab is captured idle (no job started, the demo datasets are not converted), so no progress bar is shown; the size and format of each row are visible.

**Known limit:** the Stockage tab has no translation keys in `lang/*.json`, so its labels appear in French in the EN, ES and NL captures (the French fallback strings of `js/pages/admin/tab-storage.js`). The page title and the callouts are the same in all four languages.
