## [ADDED]
- **New plugin placement `studio`**: besides `tools`, `channels` and `shaders`, a plugin can now add a *mode* to the Slice Studio (`js/modules/studio/<id>/`). Both backends list, install, enable and package it (Python and PHP twins, admin Plugins tab, setup wizard, release builder, plugin packager). A studio plugin runs in the page (in-page trust only; never sandboxed) and is ignored by the toolbar builders.
- **Plugins can declare extra scripts and styles**: `plugin.json` gains `scripts` and `styles` (paths inside the plugin folder). The registry keeps the bytes the trust gate verified and gives each plugin `ctx.plugin` — `execScripts()` runs them lazily, in order, through the same nonce path as `index.js` (styles become registry-created nonced `<style>` elements, no re-fetch), `fileUrl(rel)` hands a blob URL of a verified file (for a worker's `importScripts`) and `assetUrl(rel)` the plain URL.
- **Studio modes**: `StudioEditor.registerMode/getMode/setMode/requestClose`. The Studio header shows a *Simple | …* switch when a mode is registered and the figure suits it (a disabled button says why); a mode takes the whole Studio area. Closing the Studio, replacing its figure or leaving the page first asks the mode whether unsaved work may go (`canLeave`, `hasUnsavedWork`); a mode that throws keeps the work. The Simple Studio is unchanged when no mode is used. Opening the Studio still starts in Simple.
- **Lossless data source for studio plugins**: `ctx.studio.source.describe()` tells which planes of the volume the open figure covers, level by level (axis-aligned planes and z-stack slabs; one plane = exactly one index), and `open({ level })` holds the figure's frame (timeline paused, prefetch stopped, tree pinned once) and streams lossless 8-bit blocks (`readBlock`) from the planes tree, the format-5/6 orth rows or the bricks. `DataAccess.readRegion` accepts a `handle` so a long read never slides onto another timelapse frame.
- **Advanced Studio plugin (`studio/advanced-studio` 1.0.0, marketplace)**: an ImageJ-style view of the Studio figure on its lossless voxels — menu bar (File, Edit, Image, Process, Analyze, Window, Help), ImageJ tool bar and status bar, floating tool windows, ImageJ's plain-key shortcuts. Five tool families: Z Project (Max, Min, Sum in **16-bit** — exact up to 257 slices —, Average, SD and Median in 32-bit, streamed band by band without holding the stack), Brightness/Contrast + Channels Tool + lookup tables, selections with Measure / ROI Manager / Histogram / Plot Profile, Threshold (8 methods) with binary operations and Analyze Particles, and Gaussian / Median / Mean / Minimum / Maximum filters with Preview. Plus Undo/Redo, Crop, Duplicate, Type conversion, lossless flips and quarter turns, Math, ImageJ hyperstack TIFF export (8/16/32-bit, calibrated, LUTs and ranges) and PNG export. All computation runs in a worker on the full-precision buffers; the screen shows a tiled WebGL picture whose contrast and threshold sliders only change uniforms. Every operation is journalled in the browser (IndexedDB) and the work is offered back after a reload or a crash; nothing is ever discarded without the operator's say.

## [CHANGED]
- **Data source is 8-bit**: the stored voxels (bricks, planes, download TIFF) are 8-bit; the Advanced view says so in *Image › Show Info* and keeps every result that needs more range in 16 or 32 bits.
