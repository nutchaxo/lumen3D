## [ADDED]
- **Advanced Studio 1.6.0, the macro Recorder**: *Plugins › Macros › Record…* writes, as ImageJ 1.54p's Recorder does, the macro lines of what you do: commands with the options you chose, selections, image activation, tools, the Threshold, Brightness & Contrast, ROI Manager and Channels windows. *Create* puts the text in the Macro Editor. A running macro's own steps are never recorded. A Studio-only command gets a `// Studio only` comment, and a file picked through the browser is written as a commented line with its name, never a path of your computer. 101 Recorder sessions were captured in the real ImageJ, and the Studio writes the same lines for all but two, which the test names with their reason.
- **Script parameters `#@`**: a macro that starts with Fiji's `#@ Integer`, `#@ String (choices=…)`, `#@ Boolean`, `#@ File`… lines opens one dialog before it runs, with Fiji's labels, styles, limits and the values you entered last time. *Cancel* runs nothing. `#@output` values appear in an *Outputs* window. A parameter the browser cannot give (a service, a password field, an image when none is open) stops the macro before it runs and names the parameter. Checked against 102 scripts run in Fiji 2.18.0.
- **Installed and startup macros**: *Plugins › Macros › Install…* and the editor's *Install* button add the `macro "Name [key]"` blocks of a file to the Macros menu, with their keyboard shortcuts when the key is free, and run `AutoRun` as ImageJ does. The installed set comes back at the next Studio open without running any code until you pick a row. *Plugins › Macros › Startup Macros…* and *Edit › Options › Startup…* hold code that runs at each Studio open. *Remove Installed Macros* empties the menu. A macro that installs a set from a run never makes it come back at the next open.
- **Process › Batch › Macro**: runs a macro over every image of a granted folder (or `/tmp/`), saving each result in the chosen format into an output folder, as ImageJ's BatchProcessor does: same `i` variable, file-name filter, *Test* on the first image, progress with the file name, *Cancel* between two images, no undo step left. Formats the Studio cannot write (GIF, PGM, BMP, FITS) are shown and disabled with the reason. `run("Macro... ", …)` from a macro uses it too. Checked against 36 batch runs of the jar.
- **Process › Math › Macro**: ImageJ's expression evaluator (`v`, `x`, `y`, `z`, `w`, `h`, `a`, `d`) with live preview, on 8, 16, 32-bit and RGB images, selections and stacks, one undo step, replayed exactly from the session journal. A selection with `getPixel` follows ImageJ's rule (the whole plane, or zeros outside the selection's bounds). An endless loop in the code can be cancelled, and the Studio stays usable. 512×512 in 0.1–0.2 s. Checked against 50 cases from the jar.

## [CHANGED]
- **The macro language runs installed sets and per-pixel code**: the interpreter can now prepare a program once and run one of its macro blocks with the set's `var` values kept between runs, run per-pixel code on its fast path, and give back named variables after a run (for `#@output`).
- **A Studio op can process the whole plane while a selection is shown**: an op can declare what it does with the selection (`roiFor`), which Math › Macro uses for ImageJ's `getPixel` rule. The undo step then covers the whole plane.

## [FIXED]
- **Brightness & Contrast *Auto* starts over like ImageJ**: when a click finds no histogram range, the display is reset and the next click starts again from the first threshold, instead of halving it again.
- **Default numbers written by the Recorder round like ImageJ**: a number left as offered is written with `IJ.d2s`'s rounding (0.065 at 2 places is `0.07`), and an empty number is written `[]`.
- **ROI Manager buttons record only what they did**: *Delete* answered No, a cancelled *Rename*, *Update* with no selection, *AND / OR / XOR* with fewer than two rows and a cancelled *Properties* write nothing, and the *Show All* / *Labels* boxes write the lines ImageJ writes.
- **Opening the Batch window writes no Recorder line**: only its *Process* button writes BatchProcessor's line.
