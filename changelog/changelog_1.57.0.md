# Changelog v1.57.0 (Web Platform)

## [OPTIMIZED]

- **Studio native cuts without a 3D atlas**: XY/XZ/YZ cuts and z-stack figures of a non-stabilised dataset load into one 2D plane texture (about 0.1 GB of GPU memory instead of 1–7 GB), at a true one pixel per voxel on the largest datasets. Oblique cuts and stabilised timelapses keep the atlas, sized against the GPU budget.
- **The Studio opens faster and lighter**: the opening picture is at most 2048 px and its crop is computed from the geometry instead of a full-frame read-back and pixel scan; progressive native refreshes reuse the same buffers and GPU texture.
- **Native loads download each pack once**: bricks are fetched pack by pack from the centre outward, so the native load of the largest dataset drops from about 4.2 GB to 845 MB of downloads.
- **Pack memory released after loading**: compressed packs are kept only while their bricks are being decoded, under a 192 MiB budget, instead of up to 1.3 GB staying in memory after a native load.
- **The viewer stays within the GPU's memory**: a quality too large for the graphics card is never allocated; the next coarser level loads and the status says why, instead of the tab freezing or losing the GPU. On a weak GPU the coarsest level is still shown.
- **Lower memory use**: no CPU copy of loaded volumes, older qualities released once a heavier one is shown, the Studio frees its native picture and history on close, and the slicer releases its high-resolution buffers after a pass.
- **Faster first picture**: manifests are compressed (a 7.6 MB manifest now travels as 0.46 MB) and revalidated instead of re-downloaded, the dead seeding pause is gone, the coarsest level shows first, and scripts, styles and fonts no longer block the first paint.
- **Sharper and faster 3D rendering**: one sample per voxel at rest (thin vessels no longer vanish in projection), empty regions skipped brick by brick, resolution adapting to keep dragging fluid, no 40 FPS cap; one GPU error check per 32 bricks instead of one per brick, and composition of the channels in the decode workers.
- **Compare quality follows a shared memory budget**: panels report the memory each quality needs and are kept within one budget, lowered when another panel is added.
- **Smoother Studio navigation**: panning, zooming and dragging redraw once per screen frame, hovering no longer repaints the figure, and the minimap and Compare panel buttons are no longer rebuilt on every move.
- **Cell-tracking tools stay fluid**: the surface is recoloured with a spatial grid and cached mesh data, the neighbour chart runs in O(n) per frame and is cached, and the velocity field is one instanced mesh updated in place.
- **2D photographs**: stain isolation and display adjustments run in a background worker on the latest slider value only; the contact sheet loads thumbnails lazily; the figure panel decodes three photographs at a time.
- **Faster admin and public endpoints**: admin tab modules load on first use (about 720 KB less up front); the PHP catalog is cached and never rewrites a dataset on a public visit; plugin and language discovery no longer rewrite files or re-hash every plugin on each page load; plugin integrity checks run in parallel.

## [FIXED]

- **Native z-stack figures are native everywhere**: wherever the packer had dropped an empty brick, the Studio kept the preview for that whole column, which drew a brick-sized mosaic of brighter and duller squares in dense specimens while the figure was labelled native. An empty brick now counts as zero voxels, so every column is computed from the full-resolution data (on the 3789² test dataset 4448 bricks instead of 565, and the seams between bricks are gone). Large figures therefore show their real download size and may ask for confirmation.
- **Corrupt bricks are reported, not shown as noise**: a brick that cannot be decoded is dropped and counted, never uploaded as its compressed bytes; the status keeps the count of missing bricks and an incomplete volume is no longer cached as complete.
- **Honest native labels in the Studio**: a viewer quality or timepoint change no longer silently leaves holes in a native Studio picture; a figure with chunks still at preview resolution is labelled native-partial, and only the failed channels are downloaded again.
- **Large z-stack figures ask first**: the Studio shows the download size and offers a lower level or the preview instead of failing on the largest datasets.
- **Measurements land on the structure you click**: the depth now comes from what is displayed, including on large datasets and inside clipped or z-stack views; clicking where nothing is visible no longer records a distance to the edge of the volume's box.
- **Volumes come back after a GPU reset**: the viewer reloads the view at a lower memory budget instead of asking you to reload the page, and stops after three resets in a row.
- **Timelapses survive a failed frame**: the frame that was on screen comes back and can be retried, instead of every later frame failing; the scrubber, measurements and sync report the frame really on screen.
- **Denoise and Gaussian blur are reliable**: they work on single-channel volumes, say when they are unavailable at the current quality, blur at small sigma and match the requested sigma (the filter is in-plane, slice by slice).
- **Structure (DVR) mode looks the same while dragging and at rest**, thin slabs no longer flicker, the drag resolution recovers after a slow frame, and the grid's projection walls stay correct after a quality change.
- **Natural fluorescence render mode is selectable** in the shader menu.
- **Compare**: time sync no longer drags a timelapse you are scrubbing; every quality request gets an answer and a panel that settles below the asked quality is not reloaded again and again; a failed panel gets a Retry button and no longer blocks saving; a closed panel's camera and channels no longer reappear in the next one; boot failures are reported instead of leaving the page waiting.
- **Uncalibrated photographs say so**: a photograph with no pixel size gets no fake 1 µm/px scale bar; the Studio measures it in pixels and figures skip it in the common scale.
- **Studio**: mouse-wheel zoom follows the cursor (rotated view included); channel changes are undo steps of their own; inline text labels; histograms follow the native picture; oversized PNG exports and Studio files are refused with a clear message.
- **Language switch fixed**: switching language after plugins loaded now loads the whole interface in that language, and no longer overwrites the live status line.
- **Colour-blind filters rebuilt**: published Machado et al. 2009 matrices and true luminance for achromatopsia, applied to the page root so dialogs and toasts stay in place; the menu now says it is a simulation.
- **Keyboard shortcuts**: Ctrl/Cmd chords, auto-repeat, text fields and open dialogs no longer trigger tools; Ctrl+F and Alt+Arrow are no longer swallowed by the 2D viewer.
- **Admin: unsaved edits survive navigation**: Identity, Appearance, Legal, Pages and Types warn before you leave; saving Identity, Types or the setup wizard writes only their own settings and no longer erases what another tab changed.
- **Admin: page autosave you can trust**: a failed background save is shown and retried; changing page saves the old page first; a save from an out-of-date tab is refused instead of overwriting a newer one; autosave writes only the draft, never the published page.
- **Admin: imports survive outages**: a dropped connection pauses the transfer and resumes by itself, dead requests time out, cancel stops what is on the wire, failed files can be retried, a full server disk or an oversized file stops the import with the sizes involved, and the disk space is checked first.
- **Admin: update progress checks the new version**: one failed status request no longer announces a finished update, and an unverifiable release is refused with the reason shown.
- **Dataset edits are saved safely**: `metadata.json` is written atomically under a lock on both servers, and empty settings stay `{}`.
- **The PHP catalog is the same as the Python one**: same fields (date, markers, file size…), same visibility rules, newest-first order.
- **Tracking plugins**: the cut section shows the real outline (cavities stay empty), a malformed spot no longer drops the whole tracking layer, more than 65,535 cells are supported, and the measure tool keeps saved measurements when the plugin is torn down.
- **Smaller fixes**: plane position 0 stays 0 in the slice inspector, restoring z-stack slice 0 works, long axis names fit the orientation gizmo, empty channels show no histogram, screenshot failures are reported, exported CSV cells are safe in spreadsheets, the citation uses the instance name, and the 2D wheel zoom works in Firefox.

## [CHANGED]

- **A full audit of the platform**: viewers, Studio, streaming, memory, servers, admin, plugins and preprocessing were audited and fixed (report in `DOCS/audit/2026-10-05/`). Published datasets need no re-processing: every change works with the data already online.
- **Updates and installs must be signed**: the release key is pinned in the platform; the updater and the installer only apply the release archive named after the version, listed in a signed `SHA256SUMS` with a matching checksum, and never GitHub's raw source zip. The first update to this version is still checked by checksum only, every later one by signature.
- **Login protection holds under parallel attempts**: failed logins are counted before the password check (per address and site-wide), a wrong username takes as long as a wrong password, reverse proxies can be declared (`--trusted-proxy`, `LUMEN_TRUSTED_PROXIES` or `api/trusted-proxies.json`), and a host whose folders are read-only no longer locks the operator out.
- **Admin sessions last the promised 8 hours and end on a password change**: changing the password signs every other session out, and stored passwords are upgraded to a stronger hash at the next login. Everyone signs in once after this update.
- **Pages and dataset files are served more strictly**: only the platform's own pages get the security nonce; files under `download/` are downloaded, never rendered; XML can no longer be imported; folder listings are off; hidden datasets are no longer listed for download; scripts can never run from plugin or data folders (`js/.htaccess`).
- **Both servers behave the same**: PHP and Python apply the same login lockout, proxy handling, byte ranges, cache rules (versioned brick packs cached for a year, everything else revalidated), manifest checks and folder protections, checked by a shared test.
- **Updates keep your own .htaccess lines**: lines outside the `# BEGIN LUMEN3D` / `# END LUMEN3D` markers survive later updates. The update to this version still replaces the root `.htaccess` once: re-add any host-specific line (such as an `AddHandler`) afterwards.
- **Local development needs `--dev-trust-local`**: a checkout no longer trusts its local plugins automatically; `start_dev.bat` passes the flag. Hosts that install plugins from the marketplace are unaffected.
- **HTML blocks of the page builder are sanitised by an allowlist**: anchors, video/audio and table borders are kept; scripts, event handlers, SVG and unsafe links are removed.
- **Every test runs before every release**: CI and the release workflow run the whole suite (JS, Python, PHP); releases are created as drafts, completed, then published.
- **Readable in both themes**: muted text, primary buttons (derived from the instance colour) and light-theme badges meet WCAG AA contrast; the saved theme applies before the first paint; every page has a "Skip to content" link and named form fields; the reduced-motion setting is honoured.
- **Removed unused code**: four never-used scripts (annotations, download manifest, plane intersector), a dead annotations export and the unused `api/config.php`.
