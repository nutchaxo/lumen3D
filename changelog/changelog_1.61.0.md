# Changelog v1.61.0 (Web Platform)

## [ADDED]

- **Export pages to a file**: the *Pages* tab of the admin has an *Export* button. It lists the built-in Home and About pages and every custom page of the menu, says what each one holds (widget count, unpublished draft, default page with nothing to export), and downloads the ticked ones as one `*.lumen-pages.json` file (format `lumen-pages/1`). The file carries the published version of each page, its draft when it differs, its menu label and visibility for a custom page, the images of the media library the pages use (base64, up to 8 MB each) and the fixed page variables (`{name}` tokens) they use, so a page set moves to another instance, or into a backup, complete.
- **Import pages from a file**: the *Import* button of the same tab reads a `*.lumen-pages.json` file, or a raw `config/pages/<slug>.json` as a host serves it (slug taken from the file name). The whole file is checked before anything is written: format and version, page identifiers, the structural limits of the server (sections, columns, widgets, 2 MiB per page), image type from the magic bytes and size, variables. A refused file says why and writes nothing. The dialog shows each page with its target (editable, so a page can be imported under another identifier), whether it is new or replaces an existing or built-in page, its widget count and languages, then imports either straight to the public site (*Publish right away*) or as drafts the operator reviews and publishes from the editor. The writes go through the editor's own endpoints, one at a time: images first (an identical file already in the library is reused, a different one under the same name is stored under the name the server picks and the pages follow it), absent variables (an operator's existing value is kept and reported), the pages (`save_draft` + `publish`), then a menu row for each new custom page, hidden until it is published. An editor tab open on an imported page stops autosaving first, so it cannot write its older draft over the import. Test `tests/js/test_pages_transfer.mjs`.
