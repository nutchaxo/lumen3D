## [ADDED]
- **Advanced Studio 1.1.0 — thirty more ImageJ tools**: the ImageJ-style view of the Studio gains the tools a fluorescence confocal slice needs, ported from the ImageJ 1.54p sources (each port cites `Class.method` and quotes the lines that settle its edge cases): background and contrast, filters and image math, binary and segmentation tools, several images and channels, geometry and calibration, selections and measurements, and colocalization. 137 menu commands now, translated in English, French, Spanish and Dutch. All of it runs in the worker on the full-precision buffers, with progress and cancel, and every step is journalled, undoable and restored after a reload like the first five families.
- **Subtract Background and Enhance Contrast**: *Process › Subtract Background* (rolling ball and sliding paraboloid; Light background, Create background, Disable smoothing; ImageJ's shrink factors) and *Process › Enhance Contrast* (saturated pixels split half per tail, Normalize to the type range, Equalize with the square-root or classic table, histogram of the selection).
- **Filters and math**: Smooth, Sharpen, Find Edges (3×3, nearest edges, ImageJ's integer rounding per type), Unsharp Mask (gaussian at accuracy 0.01), Convolve (kernel text, up to 31×31, normalised only when the sum is not 0), Variance, Top Hat, Despeckle, Remove Outliers, Remove NaNs, and *Process › Math* AND, OR, XOR, Gamma, Log, Exp, Square, Square Root, Reciprocal and NaN Background, each with the per-type rules of the ImageJ processors.
- **Binary and segmentation**: Outline, Skeletonize, Distance Map (EDM), Ultimate Points, Watershed, Voronoi, and *Process › Find Maxima* with every output (Single Points, Maxima Within Tolerance, Segmented Particles, Count, Point Selection, List), Strict, Exclude edge maxima, Light background, Above lower threshold, and a live point preview over the visible area.
- **Several images and channels**: Image Calculator (Add, Subtract, Multiply, Divide, AND, OR, XOR, Min, Max, Average, Difference, Copy, Transparent-zero; divide-by-zero as the Blitters; optional 32-bit result), Split Channels, Merge Channels, Arrange Channels and Rename.
- **Geometry and calibration**: Rotate (None, Bilinear, Bicubic; Enlarge canvas; grid preview), Scale (in place or into a new window, Average when downsizing), Size, Canvas Size (nine anchors), Translate, Bin (Average, Median, Min, Max, Sum), Image Properties and Set Scale (prefilled from a straight line).
- **Selections, measurements and tables**: Wand (4- and 8-connected, tolerance, Shift to add and Alt to subtract), Segmented line and Angle tools, Specify, To Bounding Box, Enlarge, Fit Ellipse, Convex Hull, Create Mask, Create Selection; Set Measurements gains Perimeter, Bounding rectangle, Fit ellipse, Shape descriptors, Feret, Area fraction, Limit to threshold, Display label and *Redirect to* another image or channel; the ROI Manager gets *Measure* and *Multi Measure*; Summarize and Distribution; Plot Profile along a segmented line.
- **Analyze › Colocalization**: Pearson r (all pixels and above both thresholds), Manders M1 / M2 and thresholded tM1 / tM2 (the denominator is named in the column header), the Costes automatic threshold (orthogonal regression, exact for 8- and 16-bit), Li's ICQ and the overlap coefficient, with a 2D histogram plot (log counts, regression line, thresholds). The formulas come from the papers, not from any plugin code.
- **Extension API for tool packages**: `IJOpRegistry` (pixel, size, newdoc and compute operations with a version, bit depths, selection semantics, `resolve`, `scratchBytes`, preview mode), `IJApp.extend` (commands, error codes, result columns), the `api` object (`run`, `compute`, `estimate`, `preview`, `dialog` with ten field types, `overlay`, `openTable`, `openPlot`, `openTool`, `setDisplay`, `rename`), `lockDocs` for steps that read several images, and per-package loading in the worker (a package that fails to load is withdrawn alone and its commands are greyed with a tooltip).
- **Plot and table windows**: one resizable plot window (lines, bars, points, 2D density image, overlays, PNG and CSV export) and one table window (Copy and CSV save) used by Plot Profile, Histogram, Distribution, Find Maxima lists and Colocalization. Table windows are not kept across a reload (said in the About box); Results are.
- **About box**: lists the tool families and what is not in this version — stacks and 3D, macros, text and arrows, FFT, Bio-Formats, surface plots, the RGB colour type and the Wand's Legacy mode.
- **Golden fixtures from ImageJ 1.54p**: about 840 cases recorded with the real ImageJ 1.54p (`tests/fixtures/ij-wave2/`, driver in `tools/ij_fixtures/`, never run in CI) cover rolling ball and paraboloid, Enhance Contrast, 3×3 filters, Unsharp, Convolve, rank filters, Math, EDM, Watershed, Voronoi, Skeletonize, Find Maxima, the Blitter operations, Split and Merge, Rotate, Scale, Resize, Canvas, Translate, Bin, masks, the Wand, Enlarge, Feret, ellipses and thresholds to selections. The ports reproduce them bit for bit, with one documented exception (NaN Background on a selection ring).
- **Benchmark script**: `tools/bench_ij_wave2.mjs` times the heavy operations on a synthetic 5735² image per channel (8 and 16-bit). It is not a test and `tests/run_all.py` does not run it.

## [OPTIMIZED]
- **Costes threshold in one sweep**: the search no longer sorts the pixels; one pass over the pixels above both thresholds gives every level's sums from a running total, so 2048² takes about 0.5 s instead of 5 s and the longest gap between two cancel checks is under 10 ms.
- **Memory declarations are exact**: each operation declares the scratch memory it really needs before it runs (the shrunken copies of Subtract Background only when the image is shrunk, the selection mask box, the maxima sort buffers, Unsharp bands, Top Hat regions), so a step is refused or offered *without undo* for the right reason.
- **Cancel and progress at large sizes**: Subtract Background checks every row (and every 16 pixels inside a row beyond a 32-pixel ball), Watershed ticks after every level, Skeletonize every 128 rows, Rotate reports its last pass; a cancel leaves the document untouched.

## [FIXED]
- **Undo, redo and reload when the channel count changes**: baseline identity is tracked per array, so a reorder, a drop or a split no longer restores another channel's pixels; undo of a crop restores the crop origin; a stored session that cannot be replayed (unknown operation, version change, budget, missing package) is held untouched instead of being overwritten, and the page says so.
- **Display survives a reset of the range**: Subtract Background, Normalize, Equalize and Apply LUT reset only the minimum and maximum; a coloured channel no longer turns grey and an inverted LUT is kept (it changes what later binary tools and Find Maxima call the background).
- **Journal replay is exact**: the display state a step reads (inverted LUT, ranges, grey or coloured channels) is copied into the journaled parameters for Bin and Arrange Channels, as it already was for Apply LUT and Subtract Background, so a reload replays the pixels the operator saw. A binary step under an inverted LUT replays the same pixels.
- **Dialogs that stay open**: a non-modal dialog (Specify, Translate, Find Maxima, the filter dialogs, NaN Background) runs its step on the image it was opened on, or on nothing when another image became active meanwhile; before, it ran on whichever image was active at OK. The preview of the filter dialogs follows the channel chosen at open.
- **Specify and Enlarge update their fields**: ticking Centered, Square or Pixel units now changes the numbers shown, so OK no longer moves the selection by half its size or uses a distance off by the pixel size.
- **Arrange Channels keeps the selection and the view**: a reorder that holds the same arrays no longer drops the selection and re-fits the image; Split Channels of a composite shown in grey mode gives grey lookup tables, as ImageJ does.
- **Selection facts follow ImageJ**: Fit Ellipse and Convex Hull return the selections ImageJ draws, Feret and shape descriptors use the traced perimeter of a mask, Limit to threshold gives NaN thresholds when none is set, point XM and YM are raw coordinates, and a polygon with 200 000 vertices has a mask.
- **Smaller fixes**: Equalize uses the bounding rectangle of a polygon or freehand selection; Enhance Contrast statistics of line and point selections follow ImageJ; Set Scale leaves the calibration alone when OK is pressed on an untouched dialog; Rotate uses the selection at OK, not at open; the 16-bit Scale fill rounds the minimum; the ICQ is the fraction of positive products minus one half; Costes pixels exactly on a threshold count as above it; `api.state().doc` shows the display after an Invert LUT or a range change; a part of a tool that fails to load now says so instead of "Something went wrong".

## [CHANGED]
- **Selection masks follow ImageJ's PolygonFiller**: a polygon, freehand or wide-line selection is filled with ImageJ's rule (a pixel centre exactly on the left edge is outside, exactly on the right edge inside), so a triangle (0,0)-(4,0)-(0,4) now covers 10 pixels, not 6. Journal entries written by Advanced Studio 1.0.0 carry no mask rule and replay with the old fill, so a saved session reloads to the pixels it had.
- **Toolbar**: Segmented line and Angle are buttons of their own after Line, and Wand follows Point, rather than alternates of the Line button. Ctrl+Shift+P (Properties) and Ctrl+Shift+S (Smooth) are ImageJ's keys; a browser may keep them for itself, the menu entries always work.
- **Data source is still 8-bit**: results that need more range (Image Calculator with a 32-bit result, Convolve, Unsharp, Math, Costes) stay in 16 or 32 bits as before.
