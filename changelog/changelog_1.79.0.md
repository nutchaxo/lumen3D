## [FIXED]
- **Readable loading errors**: the loading error card, a failed quality switch, the GPU reload status, the 3D view export, the 2D page and the OME-Zarr / Q30 exports no longer print raw technical text (`HTTP 404 for https://…`, `Failed to fetch`, `Unexpected token <`, `Pack hash mismatch`, validator reasons). One translated sentence per kind of failure (network, not found, damaged dataset, invalid description, GPU memory, GPU lost, no bricks, busy, disk full…) comes from `Utils.friendlyError`; the detail goes to the console, and to a second line only in the admin preview.
- **The loading error stays on screen**: a missing `?id=`, an id unknown to the catalog or a rejected `metadata.json` no longer redirects to the explorer after 1.4 s; the card (with its link back) is kept. When only the catalog failed, the page opens the dataset from its own `metadata.json`.
- **A failed catalog is no longer an empty catalog**: the explorer, the landing page and the Compare picker tell "could not load" (with a Retry button) from "no datasets yet" and from "no match for these filters"; the landing counters show a dash instead of 0.
- **A bad saved view no longer takes the viewer down**: a malformed `#state=` link or workspace file is skipped with a message and the dataset opens as it was, instead of a *Loading error* card over a loaded volume; *Restore state* reports a failure instead of throwing.
- **The viewer cannot freeze on one failed frame**: an exception in the render loop is logged (first, then every 100th) and the loop keeps running; it used to stop for good.
- **Admin sign-in tells a fault from a wrong password**: only a 401 reads *Incorrect credentials*; too many attempts, a network loss and a server error each have their own message.
- **Admin writes survive a rotated session token**: a 403 caused by a second sign-in in another tab refreshes the token and resends the request once, or asks for a reload, instead of a generic *Error while saving*.
- **Admin tabs always end in a state**: a tab whose load fails (Storage, Statistics, any tab that throws on mount) shows an error with a Retry button instead of a spinner or a blank panel; a failed refresh of the import list keeps the last list; a failed first save of a new page no longer announces *Page created*.
- **Export dialogs report a refused file picker**: OME-Zarr and Q30 exports write the reason in the progress label, plugin exports show a toast on failure, instead of a Start button that seems dead.
- **Python server**: a dataset whose `name` is not text no longer breaks `catalog.json`; every GET route answers `{"error":"internal_error"}` instead of dropping the connection.
- **Malformed bodies are refused, not stored**: saving a dataset, the site identity/theme/legal documents or a media file with a body of the wrong shape or type answers 400 on both servers (it used to store `{}` stamped as configured, wipe the document, or answer 500); anonymous clients can no longer make the Python server buffer a large body before the sign-in check.
- **PHP hosts answer JSON when something goes wrong**: a shared `api/_bootstrap.php` turns `display_errors` off and answers `{"error":"internal_error"}` (500) on a fatal or uncaught exception, so a warning can no longer corrupt a JSON body nor a TypeError leave an empty 500; `api/downloads.php` no longer answers an empty 200 for a file name that is not valid UTF-8.
- **`start.bat` shipped in a release started a broken, unsafe server**: it now launches `dev_server.py` like `start_dev.bat` (the old command served the whole tree, credentials included, with no policy).

## [CHANGED]
- **Translations**: the Storage tab and several admin and viewer texts moved out of hard-coded French/English into the four language files (113 new keys, 9 corrections: `admin.reset` in French, the opening `¿` of four Spanish confirmations, a French spacing, native-load texts reading *fragments* / *Mo* in French); the quality names (*Max*, *Extra*, *High*…) and `q30` are translated; viewer menu / sidebar buttons, the Z-stack *Range* and *Interval* rows, the denoising label, the Studio align and group buttons and the slice readout follow the language.
- **Dutch is complete**: the specimen noun (*embryo* / *embryo's*) and the whole default About page now exist in Dutch; the neutral default instance carries four languages.
- **Neutral placeholders**: the landing counters and the viewer's pre-hydration texts read a dash instead of "4 datasets" / "Loading Dataset…" before the script fills them.
- **GPU downgrade notice**: no longer points to a *Render quality › GPU memory* setting that does not exist.
- **CI**: a `php-lint` job checks every `api/*.php` on PHP 7.4 and 8.3, the two ends of the supported range.
