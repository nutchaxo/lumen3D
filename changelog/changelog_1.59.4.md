# Changelog v1.59.4 (Web Platform)

## [FIXED]

- **Channel panel translated**: the histogram presets (Auto, Soft, Contrast, Reset) and the channel buttons' tooltips (Solo, Cycle opacity, Channel color, the histogram handles) stayed in English in every language, because the panel is built after the page's translation pass. The panel now translates its own markup when it is rebuilt and again on a language switch (`I18n.translateDOM(root)` accepts a subtree); the Studio's layer list does the same.
- **Viewer labels no longer hard-coded in English**: *Open in Studio (HD)*, *Open in Slice Studio*, *Clear measurements*, the Decompose panel's *Export*, the Studio's *No layers yet.* and the quality progress line (*Streaming … bricks*, *Loading … slices*) are i18n keys in the four languages. The progress line now shows while `streaming` is set in the quality state rather than by matching English words in the message.
- **Login throttle message translated**: both servers answered a French sentence on a throttled password attempt; they now answer the code `too_many_attempts` (with `retryAfter`), which the admin panel turns into *Too many attempts. Try again in N min.* in the operator's language — on the login form, the password change, a plugin approval and a marketplace install. `lockout_store_unavailable` gets its own message too.
- **Admin strings missing from every language**: the page editor's status, undo/redo, device, draft, move and media-library labels (`pages.unsaved`, `pages.savedAt`, `pages.undo`, `pages.redo`, `pages.dev.*`, `pages.discardDraft*`, `pages.draftDiscarded`, `pages.revertTitle`, `pages.moveLeft/Right`, `pages.noWidgetMatch`, `pages.copied`, `pages.media.*`) and the import errors `upl.errNoType`, `upl.errBadType`, `upl.rjUnknownType` had no entry in any `lang/*.json` (not only English and Dutch), so the French fallback in the code showed everywhere. All are now in English, French, Spanish and Dutch.
- **Password length message**: `admin.setupWeak` said 4 characters; the rule is 8. The text now takes the minimum from `MIN_PASSWORD`.
- **Explorer sort options**: two options shared the key `explorer.sortName` (French showed *Nom* twice) and the stage option borrowed the filter's label. Each option has its own key: *Name (A-Z)*, *Name (Z-A)*, *Newest first*, *Stage (earliest)*.
- **French accents restored**: about forty public French strings were written without accents (*donnees*, *Telecharger*, *A propos*, *Parametres*, *Metadonnees*, *Epaisseur*, *Resolution*…).
- **Screenshot button accented in French**: the screenshot plugin's French title read *Capture d'ecran*; it now reads *Capture d'écran* (plugin 1.1.5).
- **Downloads counted on PHP hosts**: Apache served `download/` files without PHP ever seeing them, so the Downloads statistic only moved on the Python server. A full GET of a file under `DATA_WEB/<type>/<folder>/download/` now goes through `api/download.php` (root `.htaccess`), which counts it with the same rule as `dev_server.py` — not a HEAD, not a Range continuation, only an existing file of an existing dataset — and answers a 302 to the same file marked `lumen_dl=1`, which Apache serves itself (ranges and the attachment header unchanged). `router.php` counts the same way under `php -S`.
- **Filled buttons readable in every theme colour (WCAG AA)**: white text on a button derived from a bright instance colour fell below 4.5:1 (about 4.2:1 on the wizard's orange, 3.6:1 on its turquoise). The theme compiler (`dev_server.py` and `api/site.php`, byte-identical) now writes `--color-primary-strong` and its hover itself whenever `--color-primary` is set: the colour scaled toward black from 77 % down, one percent at a time, until white text reaches 4.5:1. The Appearance tab previews the same pair (`js/pages/admin/theme-contrast.js`). An existing `config/theme.css` is recompiled once (Python at startup, PHP on the next page served). Test: `tests/test_theme_contrast.py`.
- **Organization link and footer links displayed**: `org.url` and `footer.links`, entered in the Identity tab, were saved but never shown. The public footer now lists the operator's links (http(s), mailto and relative links only) before the Legal link, and links the organization's name to `org.url` after the copyright. A localized footer copyright (one text per language) is now displayed instead of the default.
- **Dutch legal templates**: the neutral `config/defaults/neutral/legal.json` had no `nl` entry; its six sections are now in Dutch too.
- **Photograph views counted**: opening a `2d` dataset never sent a view beacon; it now counts one view per photograph per browser tab, like the volume viewer (never for an admin preview).

## [CHANGED]

- **Visits counted on every public page**: a visit used to be counted only when the home page was opened. It is now one visit per browser tab on whichever public page the visitor lands on first (`js/core/ui-actions.js`), never for the admin panel or a page embedded in another (a Compare panel, the admin preview, the page editor). The Stats tab says under each figure what it counts.
- **Documentation aligned**: `CLAUDE.md` (27 page-builder widgets, the colour-vision simulation filter, multi-range answers, four languages, what the viewer's Download Center shows, the format-4 packer beside the legacy one, how statistics are counted) and `DOCS/update-system/TECHNICAL.md` (the core update renames file by file under a journal, never the tree in one `os.replace`); user and admin guides updated to the behaviour above and their PDFs rebuilt.
