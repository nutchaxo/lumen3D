# Changelog v1.52.1 (Plateforme Web)

## [FIXED]
* **Les paquets du marketplace déclaraient encore les anciens types de données.** La v1.51.0 a renommé les types (`fixed`→`3d`, `wholemount`→`2d`) et bumpé les `plugin.json` sources en conséquence, mais les archives publiées dans `marketplace/` n'avaient pas été reconditionnées : `screenshot`, `presentation-mode`, `download-center` et `measure-distance` y déclaraient `['fixed','live','wholemount']`, et `orientation-2d`, `calibrated-grid`, `display-adjust`, `split-view`, `figure-panel` déclaraient `['wholemount']`. La porte `dataTypes` étant stricte depuis la 1.50.1, un hôte à jour qui installait ces plugins depuis le catalogue ne les chargeait plus sur le visualiseur 3D ni sur la page 2D (seul `live` restait couvert). Les dix paquets (dont `orientation-axes`, dont l'archive était restée en 1.0.0 pour une source 1.1.0) sont régénérés par `tools/publish_plugin.py` à partir des sources déjà bumpées : `calibrated-grid` 1.0.1, `display-adjust` 1.0.1, `download-center` 1.2.1, `figure-panel` 1.1.1, `measure-distance` 1.1.1, `orientation-2d` 1.0.1, `orientation-axes` 1.1.0, `presentation-mode` 1.1.1, `screenshot` 1.1.1, `split-view` 1.0.1 ; catalogue et signature Ed25519 réémis. Le noyau est identique à la 1.52.0.
