## [ADDED]
- **Advanced Studio 1.4.0, ImageJ macros**: the Advanced Studio runs ImageJ macros (`.ijm`) written in the exact language of ImageJ 1.54p. The interpreter is a port of `ij.macro`: tokenizer, recursive-descent evaluation, ImageJ's error messages with the `<token>` marker, and ImageJ's number formatting. Every built-in function is evaluated as ImageJ evaluates it. 1371 of 1410 recorded macros print exactly what the real `ij-1.54p.jar` printed. The other 39 need the user-file layer, which is not built yet. The macro runs in the Studio's worker and never on the page, so a long loop does not freeze the tab.
- **Plugins › Macros › Run… and Edit…, Window › Log**: a macro editor with line numbers, *Run*, *Run selection* (the caret's line when nothing is selected, as ImageJ's Evaluate Line does) and *Abort*. Ctrl+Enter runs the text, Ctrl+Shift+Enter runs the selection and Escape stops the run. The editor keeps its text across reloads up to 60 000 characters. `print` writes to a Log window that follows ImageJ's rules (`\\Clear`, `\\Update:`, `\\Close`), and `[Title]` text windows open as their own tabs. An error opens a Macro Error window with ImageJ's own text and a *Show in editor* link to the line.
- **`run()` covers every command of the Studio**: the 260 commands have a table that gives each one its ImageJ name, its dialog keys and its choice items. The keys were read from the real ImageJ 1.54p dialogs (`tests/fixtures/ij-macro/ij-dialogs.json`) and Fiji's macro keys. Options strings follow ImageJ: case-sensitive first-word keys, `key_0` / `key_1` for repeated keys, a bare word for a ticked checkbox and absence for an unticked one, `&variable`, `[bracketed values]`, and ImageJ's exact error when a choice is not in the list. In a macro a command answers its dialog from the options string without showing it, unless the options are empty, in which case the dialog is shown and the macro waits, as in ImageJ. `IJ.convert`'s renamed commands are honoured.
- **Images, stacks and measurements from a macro**: pixel functions (`getPixel` / `setPixel` with each type's clamping, `changeValues`, fills, lines, text), statistics, histograms, `getValue`, display ranges, calibration, `newImage` for every type, stack and hyperstack, `imageCalculator`, batch mode (hidden images that the run closes if the macro leaves them), selections and `Roi.*`, the ROI Manager, Results and `Table.*` with ImageJ's ResultsTable rules, thresholds, `Dialog.*`, `waitForUser`, `getBoolean`, `setOption`, LUTs, `getInfo`, `List.*`, and `nSlices`, `setSlice`, `getDimensions`, `Stack.*` over the stacks of 1.88.0. A 512 × 512 `setPixel(getPixel())` loop takes about 0.2 s.
- **`call()` with a short allow-list**: only a small set of risk-free static methods answers (see `DOCS/studio-advanced/macros/CALL-WHITELIST.md`). Every other `call()` stops the macro with a message.

## [CHANGED]
- **One macro run is one undo step**: Edit › Undo after a macro restores every image the run changed to its state before the run, however many commands the macro ran. Undo and Redo are refused while a macro runs. The session journal is written once at the end of the run, so a crash in the middle of a macro restores the state before it.
- **No file, network or dataset access from a macro in this version**: `open`, `saveAs`, `File.*`, `getDirectory` and the other file functions stop the macro with a message that says they come in a later version. URLs, `exec`, Bio-Formats, script languages through `eval`, and the site's datasets (File › Open from Library, the Z Project entry dialog) are refused with a reason. A macro makes no network request: a test checks the four macro files for any network API.
- **Stack dialogs record ImageJ's keys**: Concatenate's *All open windows* is `all_open` and Make Substack's *Do not create substack* is `do_not`, as in ImageJ.
- **Plugin requirement**: Advanced Studio 1.4.0 still requires the core 1.88.0. All the macro code lives in the plugin (`ij-macro-lang.js`, `ij-proc-macro.js`, `ij-macro-cmds.js`, `ij-cmds-macro.js` and the existing plugin files), and the core is unchanged.

## [FIXED]
- **Set Scale, Properties and Scale follow ImageJ in a macro**: Set Scale applies `known` and `distance` together with the pixel width, as ImageJ does when a macro runs it. Properties takes `channels`, `slices`, `frames`, `voxel_depth` and `frame` and re-dimensions the stack. Scale rewrites its options the way ImageJ does, so `-` and `0` in its fields work.
- **Commands that did nothing on a single image now behave like ImageJ**: Hyperstack to Stack and Remove Slice Labels do nothing on a single image instead of stopping with an error. Stack Statistics measures the one plane, and its columns are `Mean`, `StdDev` and so on, so `getResult("Mean", 0)` reads them.
- **Image Calculator without `create` changes the first image**, as in ImageJ, rather than opening a new one.
- **Enhance Contrast reads `process_all` and `normalize_all`**. `use` and *Equalize* with *Process all* stop the macro with a message instead of being ignored.
- **Weighted RGB conversion reaches `run("8-bit")`**: `setRGBWeights` now changes the weights of the next conversion.
- **Repeat Command honours the macro refusal list**: a command that another command runs during a macro goes through the same refusals as one the macro calls.
