# Screenshot and demo-data scripts of the documents

Archived as they were used to produce the screenshots of the administrator guide and of the
full documentation (October 2026, platform 1.59.3). They are working scripts, not a product:
paths inside them point at the scratch folder they ran from (`…/scratchpad/`), so adapt `S`,
`IMG_DIR` / `SHOT_OUT` and the `shotlib.mjs` import before re-running them.

## Set-up they assume

1. Demo data: `python gen_embryo.py <ims-dir>` writes three synthetic embryos (`.ims`), then
   `python preprocess/run_preprocess.py --input <ims-dir> --output DATA_WEB` (plus the demo
   timelapse of `preprocess/examples/ims/`). The 2D photographs were synthesised from the same
   volumes and imported with `preprocess/2d_importer.py`. Two legacy datasets (formats 1 and 2)
   were built with `2-image_processor.py --format 2` for the *Data updates* screenshots.
2. `python dev_server.py --dev-trust-local` on port 8080, an admin account, and
   `ADMIN_PASSWORD=<its password>` in the environment of the scripts.
3. Playwright + Chromium with software WebGL (`shotlib.mjs` launches it with SwiftShader).
