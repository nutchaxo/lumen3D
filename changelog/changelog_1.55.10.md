# Changelog v1.55.10 (Web Platform)

## [FIXED]

- **The admin panel no longer freezes behind a check that waits on GitHub (PHP hosts)**: PHP serialises every request of one session on the session file's lock, held from `session_start()` to the end of the script. The Updates tab fires three GitHub-bound checks the moment it mounts (update check with the release-notes bundle, plugin updates, pipeline pack) — and after an update the page reloads into that very tab — so the Datasets list, the click on a dataset and every other admin call waited in line behind GitHub, seconds each. The entry points that only read the session (auth, CSRF) now release its lock right after opening it: `api/admin.php`, `api/datasets.php`, `api/site.php`, `api/media.php` (`api/upload.php` already did); `api/auth.php` keeps it, its login writes the session. The Python server never had the lock (token sessions, threaded).
- **Pack downloads leave sockets free for the page's own requests**: a browser opens at most six HTTP/1.1 connections to a host and queues the rest in arrival order, the admin panel's calls included. With up to 24 loads in flight the preview filled every socket with pack bodies, and the next request (the metadata of the dataset just clicked, the list after a save) waited for whole packs to land — on a 5 MB/s link, ten seconds. `BrickLoader` now keeps at most four pack bodies in flight (`configure({ packFetchSlots })`, whole packs and byte runs alike; a waiting fetch leaves the queue when its dataset is switched away), which changes nothing on a bandwidth-bound link and keeps two sockets free.
- **Turning the sample over from a flat stack is a half-turn about the vertical again**: the `'tilt'` path of v1.55.9 picked the screen axis to turn about by comparing the two components of the leaning direction — and for a stack pointing straight away, the pose the sample-side switch flips from, both are floating-point noise, so the axis was a coin toss and the preview tumbled about the horizontal. The rule is now stated on what the second rotation would still have to correct (`asin|dx|` when the horizontal turns first, `asin|dy|` when the vertical does): the smaller wins, the vertical wins within five degrees of a tie, and a stack pointing straight away turns over about the vertical by construction.

Tests: `tests/test_session_release_php.php` (each read-only entry point releases the lock after opening the session and before dispatching; `$_SESSION` stays readable), `tests/js/test_brick_loader_sockets.mjs` (four bodies in flight by default, the fifth starts when one lands, the cap is configurable, a dataset switch empties the queue and frees the slots), `tests/js/test_view_frame_spin.mjs` §12 (each flip from a flat stack is a half-turn about the vertical) and §13 (pointing straight away with noise, or leaning up by under two degrees, still turns about the vertical).
